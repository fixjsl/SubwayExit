# 메타 진행(퍽 해금 및 선택 적용) 작업서

작성 2026-09-26 · 대상: `feature/meta-progression`
논문 근거: 1.1절, 1.2.1절, 3.5절, [표 3]

> 용어: 코드에서는 `Perk`, 논문 본문에서는 **특성**으로 씁니다. 논문이 전부 "특성"으로 적혀 있으므로 그대로 두시고, 4장에서 클래스 이름을 인용할 때만 `Perk`으로 표기하시면 됩니다.

---

## 0. 구조

영구히 남는 것은 **해금 목록** 하나뿐입니다. 2종은 매 세션 시작 시 그 목록에서 고릅니다. 지난 세션에서 무언가가 넘어오는 것이 아니므로 "이월"이 아닙니다.

```
세션 진행 중        전투·수집·탐색 지표 누적
게임 오버           조건을 넘긴 퍽을 해금 목록에 추가하고 파일에 저장
메인 메뉴 시작 버튼   전체 퍽 목록 표시, 해금된 것 중 최대 2종 선택 → pending에 보관
게임 씬 진입        pending을 플레이어에게 적용
```

선택은 메인 메뉴 씬에서, 적용은 게임 씬에서 일어납니다. `MetaProgressManager`가 `DontDestroyOnLoad`이므로 런타임 필드 하나로 씬을 건넙니다. **pending은 디스크에 저장하지 않습니다.**

선택 화면에는 **전체 퍽을 전부 표시**하고, 잠긴 것은 자물쇠 아이콘과 해금 조건을 보여줍니다. 플레이어가 무엇을 하면 무엇이 열리는지 알게 되므로, 1장의 "진행 방식에 따라 조건을 충족하면 해금"이 화면에 드러납니다. 4.2절 그림으로 쓸 수 있습니다.

---

## 1. 정하셔야 할 것

**퍽을 몇 개 만들지.** 아래는 축마다 2개씩 총 6개 기준입니다. 축마다 1개씩 3개로 줄여도 논문 서술("최대 2종 선택")은 충족됩니다.

**세 축의 지표.**

| 축 | 지표 | 붙일 자리 |
|---|---|---|
| 전투 | 몬스터 처치 수 | `MonsterStateMachine`의 사망 처리 |
| 수집 | 아이템 획득 수 | `Inventory.AddItem` |
| 탐색 | 비상구로 귀환 성공 횟수 | `BaseReturnExit.OnInteractInternal` |

탐색을 `CycleManager.ExecuteCycleReset`에서 세면 안 됩니다. **사망도 같은 함수를 부르기 때문에** 실패가 탐색 성과로 잡힙니다.

**잠긴 퍽의 이름을 가릴지.** `???`로 가리면 해금의 재미가 있고, 보여주면 목표가 명확합니다. 조건 문구는 어느 쪽이든 보여주세요.

## 2. 새 파일 다섯 개

### `Assets/Script/Status/Perk.cs`

```csharp
using UnityEngine;

public enum PerkAxis { Combat, Gather, Explore }

[CreateAssetMenu(fileName = "Perk", menuName = "Scriptable Objects/Perk")]
public class Perk : ScriptableObject
{
    public int perkId;
    public string perkName;
    [TextArea(2, 4)] public string description;
    public Sprite icon;

    [Header("해금 조건")]
    public PerkAxis axis;
    public int threshold;

    [Header("효과")]
    public int maxHpBonus;
    public int maxStaminaBonus;
    public float carryWeightBonus;
    public ItemBase startingItem;

    public string GetConditionText()
    {
        string axisName = axis switch
        {
            PerkAxis.Combat  => "전투",
            PerkAxis.Gather  => "수집",
            PerkAxis.Explore => "탐색",
            _ => ""
        };
        string unit = axis switch
        {
            PerkAxis.Combat  => "마리 처치",
            PerkAxis.Gather  => "개 획득",
            PerkAxis.Explore => "회 귀환",
            _ => ""
        };
        return $"{axisName} {threshold}{unit}";
    }

    public void Apply(PlayerStatus status, Inventory inventory)
    {
        status.Maxhp          += maxHpBonus;
        status.MaxStamina     += maxStaminaBonus;
        status.maxCarryWeight += carryWeightBonus;
        if (startingItem != null) inventory.AddItem(startingItem, 1, true);
    }
}
```

`AddItem`의 세 번째 인자 `suppressFirstAcquire`를 `true`로 주세요. 세션 시작 지급인데 최초 획득 연출이 뜨면 어색합니다.

**효과는 이 넷에서 늘리지 마세요.** 넷 다 `PlayerStatus`의 기존 필드라 그쪽을 건드리지 않고 끝납니다.

### `Assets/Script/Manager/MetaProgressManager.cs`

```csharp
using System.Collections.Generic;
using System.IO;
using UnityEngine;

public class MetaProgressManager : MonoBehaviour
{
    public static MetaProgressManager Instance { get; private set; }

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
    static void ResetStatics() => Instance = null;

    [SerializeField] private Perk[] allPerks;

    public MetaProgress progress { get; private set; } = new MetaProgress();
    public IReadOnlyList<Perk> AllPerks => allPerks;

    // 메인 메뉴에서 고른 퍽. 씬을 건너기 위한 런타임 보관이며 저장하지 않는다.
    private readonly List<Perk> pending = new List<Perk>();

    // 세션 중 누적 지표
    public int killCount   { get; private set; }
    public int gatherCount { get; private set; }
    public int runCount    { get; private set; }

    private string savePath => Path.Combine(Application.persistentDataPath, "progress.json");

    void Awake()
    {
        if (Instance == null) { Instance = this; DontDestroyOnLoad(gameObject); }
        else { Destroy(gameObject); return; }
        Load();
    }

    void Load()
    {
        if (File.Exists(savePath))
            JsonUtility.FromJsonOverwrite(File.ReadAllText(savePath), progress);
    }

    public void Save() => File.WriteAllText(savePath, JsonUtility.ToJson(progress, true));

    public bool IsUnlocked(Perk p) =>
        p != null && progress.unlockedPerkIds.Contains(p.perkId);

    // ── 선택 보관 및 적용 ─────────────────────

    public void SetPending(IReadOnlyList<Perk> perks)
    {
        pending.Clear();
        if (perks != null) pending.AddRange(perks);
    }

    public void ApplyPending(PlayerStatus status, Inventory inventory)
    {
        foreach (var p in pending)
            if (p != null) p.Apply(status, inventory);
    }

    // ── 세션 지표 ─────────────────────────────

    public void BeginSession() => killCount = gatherCount = runCount = 0;

    public void AddKill()        => killCount++;
    public void AddGather(int n) => gatherCount += n;
    public void AddRun()         => runCount++;

    // ── 해금 ─────────────────────────────────

    /// 게임 오버 시 호출. 새로 해금된 퍽 목록을 돌려준다.
    public List<Perk> EvaluateUnlocks()
    {
        var newly = new List<Perk>();
        foreach (var p in allPerks)
        {
            if (p == null || IsUnlocked(p)) continue;

            int value = p.axis switch
            {
                PerkAxis.Combat  => killCount,
                PerkAxis.Gather  => gatherCount,
                PerkAxis.Explore => runCount,
                _ => 0
            };

            if (value >= p.threshold)
            {
                progress.unlockedPerkIds.Add(p.perkId);
                newly.Add(p);
            }
        }
        if (newly.Count > 0) Save();
        return newly;
    }
}
```

`pending`이 담는 것은 ScriptableObject 참조입니다. 에셋이므로 씬이 바뀌어도 살아 있습니다.

### `Assets/Script/UI/PerkSelectUI.cs`

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class PerkSelectUI : MonoBehaviour
{
    public static PerkSelectUI Instance { get; private set; }

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
    static void ResetStatics() => Instance = null;

    [SerializeField] private GameObject panel;
    [SerializeField] private Transform buttonContainer;
    [SerializeField] private PerkButton buttonPrefab;
    [SerializeField] private Button confirmButton;
    [SerializeField] private Sprite lockedSprite;
    [SerializeField] private Color selectedColor = Color.yellow;
    [SerializeField] private bool hideLockedName = true;

    private readonly List<Perk> selected = new List<Perk>();
    private readonly Dictionary<Perk, Image> buttonImages = new Dictionary<Perk, Image>();
    private Action<IReadOnlyList<Perk>> onConfirmed;

    void Awake()
    {
        Instance = this;
        panel.SetActive(false);
        confirmButton.onClick.AddListener(Confirm);
    }

    public void Show(Action<IReadOnlyList<Perk>> callback)
    {
        if (buttonPrefab == null) { Debug.LogError("[PerkSelectUI] buttonPrefab 없음"); return; }

        var mgr = MetaProgressManager.Instance;
        if (mgr == null) { Debug.LogError("[PerkSelectUI] MetaProgressManager 없음"); callback?.Invoke(null); return; }

        onConfirmed = callback;
        selected.Clear();
        buttonImages.Clear();

        for (int i = buttonContainer.childCount - 1; i >= 0; i--)
            Destroy(buttonContainer.GetChild(i).gameObject);

        foreach (var item in mgr.AllPerks)
        {
            if (item == null) continue;

            var perk = item;                       // 클로저 캡처용 지역 변수
            bool unlocked = mgr.IsUnlocked(perk);

            var pb = Instantiate(buttonPrefab, buttonContainer);
            pb.gameObject.SetActive(true);

            pb.button.interactable = unlocked;
            pb.icon.sprite = unlocked ? perk.icon : lockedSprite;
            pb.label.text  = unlocked
                ? $"{perk.perkName}\n{perk.description}"
                : $"{(hideLockedName ? "???" : perk.perkName)}\n{perk.GetConditionText()}";

            buttonImages[perk] = pb.background;

            if (unlocked) pb.button.onClick.AddListener(() => Toggle(perk));
        }

        panel.SetActive(true);
    }

    private void Toggle(Perk perk)
    {
        if (selected.Contains(perk)) selected.Remove(perk);
        else if (selected.Count < 2) selected.Add(perk);
        else return;                               // 2개 초과는 무시

        foreach (var pair in buttonImages)
            if (pair.Value != null)
                pair.Value.color = selected.Contains(pair.Key) ? selectedColor : Color.white;
    }

    private void Confirm()
    {
        var cb = onConfirmed;                      // 콜백을 먼저 붙잡아 둘 것
        var result = new List<Perk>(selected);

        panel.SetActive(false);
        onConfirmed = null;

        cb?.Invoke(result);
    }
}
```

**두 가지를 빠뜨리지 마세요.**

`var perk = item;`으로 지역 변수에 받는 것. `foreach` 변수를 그대로 람다에 캡처하면 마지막 항목만 잡힐 수 있습니다.

`Confirm`에서 콜백을 `cb`에 먼저 받아두는 것. `ZoneSelectUI`에서 이 자리를 놓쳐 버튼이 먹통이 됐었습니다.

잠긴 퍽은 `interactable = false`라 유니티가 회색 처리하고 클릭도 막습니다. 리스너를 아예 안 달았으니 이중으로 안전합니다.

## 3. 기존 코드에 붙일 여섯 곳

### 3.1 퍽 선택 — `StartMenu.OnStart()`

시작 버튼을 누르면 퍽을 먼저 고르고, 그다음 인트로 영상이 나가도록 순서를 바꿉니다. 영상이 로딩을 가려주는 자리이므로 선택이 그 앞에 오는 게 자연스럽습니다.

```csharp
void OnStart()
{
    if (PerkSelectUI.Instance == null) { OnPerksSelected(null); return; }

    StartMenuPanel.SetActive(false);
    PerkSelectUI.Instance.Show(OnPerksSelected);
}

private void OnPerksSelected(IReadOnlyList<Perk> perks)
{
    MetaProgressManager.Instance?.SetPending(perks);
    PlayIntroThenLoad();
}

private void PlayIntroThenLoad()
{
    if (videoPlayer == null || videoPlayer.clip == null)
    {
        LoadGameScene();
        return;
    }

    StartMenuPanel.SetActive(false);
    videoPanel.SetActive(true);
    skipButton.gameObject.SetActive(true);
    videoPlayer.Play();
}
```

기존 `OnStart()`의 영상 재생 부분을 `PlayIntroThenLoad()`로 떼어낸 것뿐입니다. `PerkSelectUI.Instance` 널 체크는 프리팹 연결을 깜빡했을 때 시작 버튼이 아무 반응 없이 죽는 걸 막아줍니다.

### 3.2 퍽 적용 — `GameStartFlow.OnWeaponSelected()`

게임 씬에서 실제로 플레이가 시작되는 지점입니다.

```csharp
public void OnWeaponSelected()
{
    weaponCardContainer.SetActive(false);
    PlayerStateMachine.Instance.SetMovementLocked(false);

    var player = PlayerStateMachine.Instance;

    LootTable.ResetUniquesForNewSession();                       // 유니크 드롭 기록 초기화
    MetaProgressManager.Instance?.ApplyPending(player.status, player.inventory);
    player.status.Hp = player.status.Maxhp;                      // Maxhp를 올렸으므로 다시 채움

    MetaProgressManager.Instance?.BeginSession();                // 지급분이 수집에 안 잡히도록 뒤에 호출

    Time.timeScale = 1f;
    GameManager.Instance.TutorialStart();
}
```

**`BeginSession()`을 `ApplyPending()` 뒤에 부르는 게 핵심입니다.** 퍽의 시작 아이템 지급도 `AddItem`을 거치는데, 먼저 부르면 그게 수집 지표에 잡힙니다.

`Hp` 재설정이 필요한 이유는 `PlayerStatus.Hp`의 setter가 `Maxhp`로 클램프하기 때문입니다. 최대 체력만 올리고 현재 체력을 안 채우면 플레이어가 손해를 봅니다.

### 3.3 전투 지표 — 몬스터 사망 시

`MonsterStateMachine`의 사망 처리(`OnDieHandler` 또는 `Die` 상태의 `Enter`)에 한 줄.

```csharp
MetaProgressManager.Instance?.AddKill();
```

보스도 셀지 정하세요. 별도 축으로 두면 퍽이 하나 더 필요하니 지금은 같이 세는 쪽을 권합니다.

### 3.4 수집 지표 — `Inventory.AddItem`

성공 반환 직전에 한 줄씩. `AddItem`은 성공 경로가 둘(기존 슬롯 누적 / 새 슬롯)이니 **양쪽 다** 넣으셔야 합니다.

```csharp
MetaProgressManager.Instance?.AddGather(num);
```


비상구로 귀환에 성공했을 때만 세집니다.

### 3.6 세션 종료 — `GameOverUI.Show()`

해금 평가만 합니다. 선택은 다음 세션의 메인 메뉴로 옮겼으니 여기서는 UI를 띄우지 않습니다.

```csharp
private void Show()
{
    panel.SetActive(true);
    Time.timeScale = 0f;
    Cursor.lockState = CursorLockMode.None;
    Cursor.visible = true;

    var newly = MetaProgressManager.Instance?.EvaluateUnlocks();
    // newly.Count > 0 이면 게임오버 패널에 "새 특성 해금: ○○"을 표시
}
```

새로 해금된 게 있으면 이름만 나열해 주세요. 플레이어가 다음 판에 뭘 고를 수 있는지 알게 됩니다.

## 4. 씬 작업

### 프리팹으로 만들 것

**`MetaProgressManager`를 프리팹으로 만들어 두 씬에 각각 배치하세요.** 빈 오브젝트를 따로 두 번 만들면 `allPerks` 배열이 두 벌이 되어, 나중에 퍽을 추가할 때 한쪽만 고치게 됩니다. 프리팹이면 배열이 한 군데입니다.

역할은 이렇게 나뉩니다. **메인 메뉴 씬의 것이 실제로 일합니다.** 해금 목록을 조회하고 선택을 `pending`에 담고 `DontDestroyOnLoad`로 게임 씬까지 따라갑니다. **게임 씬의 것은 개발 편의용**이라, 정상 흐름에서는 싱글턴 가드가 바로 파괴합니다. 에디터에서 게임 씬만 재생할 때 매니저가 없어 널이 되는 걸 막아줍니다.

### 메인 메뉴 씬

- `MetaProgressManager` 프리팹
- `PerkSelectUI` — 메인 메뉴 캔버스에. 시작 버튼을 눌렀을 때 뜰 패널

### 게임 씬

- `MetaProgressManager` 프리팹

### 버튼 프리팹

`PerkButton` 컴포넌트를 붙이고 `button`, `background`, `icon`, `label` 넷을 인스펙터에서 연결하세요. 레이아웃은 `ZoneSelectUI`의 것을 복제해 쓰시면 빠릅니다.

**Project 창의 프리팹 에셋을 연결하세요.** 씬 오브젝트를 넣으면 컨테이너를 비울 때 같이 지워져 `MissingReferenceException`이 납니다. 지난번에 겪은 그것입니다.

### 그 밖에

- 자물쇠 스프라이트 하나 (`lockedSprite`)
- 퍽마다 아이콘 스프라이트
- 컨테이너에 `Grid Layout Group`. `Constraint`를 `Fixed Column Count`로 두고 3 정도. 퍽이 6개면 3×2로 떨어집니다
- 항목 수에 따라 패널이 늘어나야 하면 `Content Size Fitter`의 Vertical Fit을 `Preferred Size`로

## 5. 테스트

- [ ] 첫 실행에서 `progress.json`이 없어도 정상 시작되는지
- [ ] 첫 세션에서 전체 퍽이 전부 자물쇠로 표시되고, 조건 문구가 보이는지
- [ ] 잠긴 퍽이 클릭되지 않는지
- [ ] 아무것도 안 고르고 확인 → 영상으로 넘어가고 정상 시작되는지
- [ ] 몬스터를 잡고, 아이템을 먹고, 비상구로 한 번 귀환한 뒤 게임오버 → 해금이 뜨는지
- [ ] `progress.json`의 `unlockedPerkIds`에 값이 들어가는지
- [ ] 메인 메뉴로 나갔다가 시작 버튼 → 해금된 퍽이 아이콘으로 바뀌고 클릭되는지
- [ ] 2개까지만 골라지는지, 다시 누르면 해제되는지
- [ ] 고른 뒤 게임 씬에서 최대 체력과 소지 무게가 올라가 있는지, 체력이 가득 차 있는지
- [ ] 시작 아이템이 있는 퍽을 골랐을 때 인벤토리에 들어오는지
- [ ] 두 번째 게임오버에서 이미 해금된 퍽이 중복으로 안 뜨는지
- [ ] **게임오버 → 메인 메뉴 → 새 게임에서 유니크 아이템이 다시 드롭되는지**
- [ ] 에디터에서 게임 씬을 직접 재생해도 오류 없이 시작되는지

`progress.json`의 위치는 `%USERPROFILE%\AppData\LocalLow\<회사명>\<제품명>\progress.json`입니다. 직접 열어보면 저장 여부가 바로 확인됩니다.

## 7. 논문에서 고칠 것

**3.5절** — "이월"이 부정확합니다. 영구히 남는 것은 해금 목록이고 2종은 매 세션 고르는 것이므로, 지난 세션에서 무언가가 넘어오지 않습니다.

> 플레이어가 이전 세션들에서 해금한 특성 중 최대 2종을 선택하여 다음 세션에 ~~이월~~ **적용**할 수 있다.

**4장 표 8의 3.5행** — "세션 종료 시 특성 2종 이월 메타 진행 연동"을 "세션 종료 시 조건 충족분 해금, 다음 세션 시작 시 2종 선택 적용"으로.

**3.5절에 해금 조건 한 문단 추가** — 지금은 "조건을 충족하면"이라고만 되어 있어 조건이 무엇인지 나오지 않습니다. 전투·수집·탐색 세 축과 각 임계값을 서술하세요.

**퍽 목록 표** — 무기 4종을 [표 2]로 제시하셨으니 퍽도 표로 두면 일관됩니다. 이름, 해금 조건, 효과 세 열이면 충분합니다.

**4.2절 그림** — 퍽 선택 화면을 그림으로 넣으세요. 잠긴 퍽과 해금된 퍽이 한 화면에 같이 보이므로, 해금 조건이 플레이어에게 제시된다는 점이 한 장으로 설명됩니다.
